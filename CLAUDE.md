# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Repository purpose

This is not a software project. It's Ishan's personal daily log of work done at the Maker-Space at CFAL India. There is no build, lint, or test tooling — the only content is Markdown log entries.

## Structure

- `daily-log/YYYY-MM.md` — one Markdown file per month, containing dated entries for that month.
- `daily-log/YYYY/` — per-year directory (currently empty; reserved for future per-year content).

## Conventions

- When adding a new day's entry, append to the current month's `daily-log/YYYY-MM.md` file, creating it if it doesn't exist yet.
- Keep entries factual and dated; this repo is a record of activity, not a place for generated commentary.
